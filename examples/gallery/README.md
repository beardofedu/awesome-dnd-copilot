# Fictional example gallery

Browse representative inputs and outputs before choosing an agent or session
kit. These are original, hand-authored illustrations, not recorded model runs
or quality guarantees. Each campaign is independent unless a page says otherwise.
No published adventure text, art, real campaign secrets, or personal data is
included. See the [attribution guidance](../../ATTRIBUTION.md) when reusing
material.

## Read the labels first

Review status and intended audience are separate:

| Label | Meaning in this gallery |
|---|---|
| **Draft** | Proposed output awaiting human review; not established canon or approved for sharing. |
| **DM-reviewed example** | An explicitly simulated DM decision illustrates accepting, changing, or rejecting a draft. It is not approval for your campaign. |
| **Player-safe example** | An illustrative player-facing extract containing only information intended for the fictional players. It still needs your review before reuse. |

A DM-reviewed draft can remain DM-only. A player-facing draft can remain
unapproved. No label, folder, branch, hidden panel, or passing check restricts
repository access or proves spoiler safety.

## Try a sample without publishing

Open the linked agent or kit, then use its sample input in a private DM
workspace. For agents, follow the repository's
[installation guidance](../../README.md#installation-destinations-and-activation);
for kits, follow the linked kit README. Compare the result's structure,
source fidelity, unresolved questions, and player agency with the example,
not its exact wording. Output will vary.

Review every proposed fact before treating it as canon. If sharing is needed,
manually prepare and review a separate player-facing extract, following the
[player-safe release process](../../campaign-maintenance/session-kits/player-safe-release/README.md).
Only approved final material belongs in a separate player workspace; do not
copy this whole gallery, drafts, or review notes into a campaign's player
repository. Review for the intended players is not permission for public
publication.

Reading or copying these samples activates no tools, automations, workflows,
or GitHub Pages. Nothing here requires a connected account or a live campaign.
For an end-to-end installation and sharing walkthrough, see
[First campaign](../first-campaign/README.md).
