# Player-approved fictional character goal

Complete only for a fictional character. The player may leave anything blank,
decline, revise, or withdraw approval at any time. The DM should keep this
intake in a DM-only repository and use only the goal text and boundaries the
player explicitly approved.

```markdown
## Character
Character name:
Player-provided goal, in the player's own words:

## Optional story use approval
I approve using the goal above for DM-only brainstorming of optional hooks
connected to the supplied approved quests. This does not approve any particular
plot event, reveal, relationship, character action, consent, or reward.
Approval: yes / no

## Boundaries for this brainstorming
Topics, reveals, relationships, or outcomes to avoid:
Anything that must remain undecided or require my character's choice:

## DM-maintained approved quest context
Quest title:
Brief approved description:
Source link(s):
```

Do not add personal explanations for the goal, or health or identity
information. Do not treat blank fields, silence, or past choices as approval.
Reconfirm scope after a material change to the goal or boundaries.
