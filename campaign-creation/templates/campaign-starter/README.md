# Campaign workspace

This is an empty starting structure, not approved campaign canon. Keep this
repository accessible only to the DM and trusted co-DMs; folders do not enforce
access control. A local directory or this template does not create a repository
or change its permissions.

1. Fill in `campaign.md` with the table's agreed details; avoid personal data.
2. Record DM-approved facts in `canon/`, session records in `sessions/`, and
   future plans in `prep/`. AI drafts are proposals until the DM approves them.
3. For players, review and manually copy only approved material to a separate,
   player-accessible repository. See `public-export/README.md`. Never share this
   private workspace or assume a folder hides secrets from repository readers.
4. Review the selected Copilot instructions, agents, and kit READMEs before use.
   Kit examples are fictional; copying files does not activate any service.
